# 交互演示

以下演示页面展示了 Z-Board 的核心功能，可以在浏览器中直接体验。

## 演示列表

### 🎨 白板演示

全屏体验完整的白板功能：画笔、图形、文字、橡皮擦、指针选择、撤销重做、翻页、图片导出等。

[进入演示 →](/play/whiteboard.html)

### 📸 截图演示

截图标注功能：框选截图区域、画笔标注、图形标注、文字批注、导出截图结果。

[进入演示 →](/play/screenshot.html)

---

::: tip 提示
演示页面为独立 HTML，不引入 VitePress 样式。白板和截图数据变化会输出到浏览器控制台，可打开 DevTools 查看。
